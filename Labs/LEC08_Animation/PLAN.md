# Drill #8. 애니메이션 뷰어 — 작업 계획

## 요구사항 정리
- [ ] Sprite Sheet 준비 (구글 검색 혹은 AI 이용)
- [ ] 애니메이션 최소 4종 (예: 걷기, 뛰기, 점프, 공격)
- [ ] 캐릭터가 너무 작으면 확대 (화면 절반 이상)
- [ ] 파일명 `animation_viewer.py`, `LEC08` 폴더(본 저장소 기준 `Labs/LEC08_Animation`)
- [ ] 화면 중앙에서 재생
- [ ] 애니메이션 5회 반복 후 1초 정지, 모든 애니메이션을 순서대로 무한 반복
- [ ] (보너스) 프레임마다 크기가 다른 복잡한 Sprite Sheet 사용 + 언급
- [ ] (보너스) 애니메이션별 프레임 수가 다른 경우 지원 + 언급
- [ ] 커밋 20개 이상, 의미 있는 단위로 작성

## 에셋 선택
수업 자료 폴더(`Labs/LEC08_Animation`)에 이미 제공된 `SamuraiSheet.png`를 사용한다.
- 투명 배경 PNG, 여러 동작(대기/걷기/달리기/구르기·점프/공격 등)이 행(row) 단위로 배치되어 있음
- 행마다 프레임 개수가 다르고, 프레임마다 실제 그림 크기(가로/세로)도 다름
  → 두 보너스 항목을 자연스럽게 만족시킬 수 있는 소재

## 구현 전략
1. 스프라이트 시트를 알파 채널 기준으로 분석해 각 프레임의 "실제 그림이 있는 영역"만
   자동으로 잘라내는 스크립트를 작성한다 (`build_manifest.py`).
2. 그 결과를 JSON 매니페스트(`samurai_manifest.json`)로 저장한다.
3. `animation_viewer.py`는 이 매니페스트를 읽어 pico2d의 `clip_draw(left, bottom, w, h, x, y, draw_w, draw_h)`
   로 프레임을 잘라 그리고, 항상 같은 "표시 높이"로 확대해서 그린다.
4. 애니메이션 재생 상태(반복 횟수, 정지 여부)는 별도 클래스에서 관리한다.
